# Saracho Neumáticos — VTEX

Respaldo privado y exportable del trabajo realizado en ChatGPT para el proyecto **Saracho Neumáticos + VTEX**.

## Contenido

- `CHATGPT_TRANSCRIPCION.md`: transcripción cronológica recuperada de la conversación original (20 turnos).
- `REGLAS_PROYECTO.md`: criterios consolidados para catálogo, Producteca, VTEX, dimensiones, SEO y reportes.
- `docs/producteca/`: guía operativa, fuente de imágenes y Excel de ejemplo para
  las altas masivas de Producteca.
- `installments-info-sarachoneumaticos/`: código fuente de la aplicación VTEX IO de financiación y promociones.
- `installments-info-sarachoneumaticos-v0.0.19.zip` y `v0.0.20.zip`: versiones empaquetadas de la aplicación.
- `outputs/`: planillas de catalogación y reportes, documentos comparativos, capturas de revisión y archivos de Mercado Libre.
- `build_vtex_tiendanube_report.py`: generador del informe comparativo de plataformas.

## Cómo exportar

Desde GitHub se puede descargar una copia completa con **Code → Download ZIP**. También puede clonarse con Git:

```bash
git clone https://github.com/bissojoaquin-sketch/saracho-neumaticos-vtex.git
```

## Privacidad

El repositorio se publica como **privado** porque contiene transcripciones y documentación comercial. No cambiar su visibilidad sin revisar antes los archivos.

## Nota sobre los adjuntos históricos

La transcripción conserva referencias a adjuntos que no estaban disponibles durante la extracción original. Los archivos recuperados posteriormente están organizados en `outputs/`.
